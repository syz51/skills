# Security policy

Security fixes target the latest version on `main`. Older snapshots do not have a separate support commitment.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/syz51/skills/security/advisories/new) to report a suspected vulnerability in the skills or evolution tools. Include the affected revision, a minimal reproduction, expected impact, and relevant configuration with secrets and personal information removed.

Do not post credentials, private transcripts, identifying feedback, or exploit details in public issues or pull requests. If a minimal reproduction would still disclose sensitive material, describe the issue privately before sharing that material.

Capture and verification can send redacted completed-session text to a model. Redaction is not a guarantee that every sensitive detail has been removed. Keep real evidence and authentication outside this repository, and explicitly choose source directories before enabling those tools.

Reports will be assessed for impact and a suitable fix. This project does not promise a response deadline or a guaranteed outcome.
